Developer Use

The specification should be used together with the DFD page, journey map and platform prototype. A development team can use it to estimate MVP1, define the data model, structure API boundaries, assign permissions, create the backlog and confirm acceptance criteria before implementation.

Language note: translations are provided to support execution. If a translated version conflicts with the English source, the English document prevails.
