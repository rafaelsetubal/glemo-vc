TOKEN GOVERNANCE POLICY

Token Governance Policy

Asset-class-neutral liquidity and distribution rail for tokenized real-world assets.

The token is a supporting ecosystem layer for dApps, AI agents and network contribution. It is not the core investment thesis.

Primary Token Objective

The GO token should incentivize delivery, integration and useful participation around the GlemO platform, especially third-party dApps, AI agents, data workflows, marketplace tooling and verified network contribution.

Purpose Lock

The company must be able to win without token speculation. The rail, marketplace front, sourcing engine, buyer activation, compliance workflow and operating evidence remain the core product.

Permitted usePurposeEvidence
dApp delivery incentivesReward useful applications and integrations on top of the platform.Acceptance record, usage data, code or integration proof.
AI-agent incentivesImprove sourcing, buyer activation, reporting, diligence or operational automation.Agent logs, workflow output, partner usage and security review.
Developer ecosystemSupport SDKs, APIs, modules and integrations.Documentation, activity, usage, maintenance.
Verified contributionReward measurable participant work that improves the network.Campaign ledger, anti-abuse checks, governance approval.

Prohibited Read

  • The token does not represent a claim on RWA revenue, asset cash flow, company equity or investor distributions.
  • The token does not guarantee liquidity, price support, market depth or access to regulated assets.
  • The token should not become the main fundraising story, valuation argument or substitute for platform execution.
  • Any public token communication remains subject to counsel review and jurisdictional rules.

Approval Requirement

Any material change to the token objective must require unanimous written approval from all project equity partners and investor consent parties defined in the definitive financing documents, including participating VCs where applicable.
